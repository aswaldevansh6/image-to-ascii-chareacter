# Image-to-ASCII Converter

## Project Description
A Python-based image processing application that converts
digital images into ASCII art using pixel intensity mapping.

## Technologies Used
- Python
- Pillow
- NumPy
- Matplotlib
- Streamlit

## Main Features
- Upload JPG and PNG images
- Convert images into grayscale
- Resize images
- Map pixel brightness to ASCII characters
- Visualize original and grayscale images
- Adjust ASCII output width
- Invert brightness
- Download ASCII output as TXT

## Installation

Install dependencies:

pip install -r requirements.txt

## Run Application

streamlit run app.py
